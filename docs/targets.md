# 翻訳対象一覧

基準は kry-planet-mods-lite 1.1.3（Factorio 2.1）の依存MODと、その前提MODです。
キー数は英語ロケールの行数（各MODの2.1対応版で数えたもの）です。

状態の見方:
- **訳済み** … このMODで訳した
- **対象** … このMODで訳す（未着手）
- **AJP** … Any_Japanise_Pack が訳済みなので扱わない
- **TPJ** … Translate_planet_into_Japanese（惑星Mod 日本語化パック）が訳済みなので扱わない
- **本体** … MOD本体に日本語ロケールが入っているので扱わない
- **なし** … 表示文字列がない
