# All Planet Mods 日本語化（planets-japanese）

[Kry's All Planet Mods](https://mods.factorio.com/mod/kry-all-planet-mods)（と lite 版）に含まれる惑星MODと、その前提MOD約70個を日本語化するFactorio MODです。
パックの作者とは関係のない、有志の日本語化MODです。

> **AIによる機械翻訳です。** 訳語の統一やタグの確認はしていますが、ゲーム内ですべての表示を確かめたわけではありません。不自然な訳や誤訳を見つけたら Issue で教えてください。

## 使い方

ゲーム内のMODメニュー（またはMODポータル）で「All Planet Mods 日本語化」を探して、有効にするだけです。
Factorio 2.0 と 2.1 のどちらでも、自分のバージョンに合ったものが入ります。
言語設定を日本語にしておいてください。

## ほかの日本語化MODとの併用

次のMODと一緒に使えます。これらがすでに訳しているところは、このMODには入れていません。

- [Any_Japanise_Pack](https://mods.factorio.com/mod/Any_Japanise_Pack)
- [惑星Mod 日本語化パック](https://mods.factorio.com/mod/Translate_planet_into_Japanese)

MOD本体に日本語訳が入っている部分も、本体の訳を優先しています。

## 対応MOD

主な対応MOD: Arig / Hyarion / Tellus / Panglia / Muria / Linox / Foliax / Crucible / Rabbasca / Eneas ほか。
全一覧は [docs/targets.md](docs/targets.md) にあります。

訳語は Factorio 公式の日本語訳に合わせています（一覧は [docs/glossary.md](docs/glossary.md)）。
